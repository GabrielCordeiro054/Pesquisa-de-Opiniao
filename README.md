# 📊 Pesquisa de Opinião - TudoWeb

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião com clientes da empresa de marketing TudoWeb.

O programa coleta o **nome**, a **idade** e a **opinião sobre o atendimento** de cada entrevistado.

As opções de opinião são:

* **1 - EXCELENTE**
* **2 - BOM**
* **3 - RUIM**

## 💻 Funcionamento

O programa utiliza uma estrutura de repetição `for` para realizar a pesquisa com os entrevistados.

Também são utilizadas estruturas de decisão `if` e `elif` para verificar a opinião informada e contabilizar as respostas **EXCELENTE** e **RUIM**.

Ao final da pesquisa, o programa apresenta na tela a quantidade de respostas:

* EXCELENTE
* RUIM

## 🧪 Teste

Para validar o funcionamento do programa, foi realizado um teste com **10 entrevistados**.

O teste verificou se o programa conseguia receber os dados corretamente e contabilizar as respostas de acordo com a opinião escolhida.

Após o teste, o programa foi configurado novamente para realizar a pesquisa com **50 entrevistados**, conforme solicitado na atividade.
